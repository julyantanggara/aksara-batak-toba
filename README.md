# Pengumpulan Tulisan Aksara Batak Toba

Halaman web untuk **mengumpulkan tulisan tangan 117 aksara Batak Toba** (penelitian skripsi). Buka tautan
GitHub Pages repositori ini, tulis setiap aksara di kotaknya, lalu klik **Unduh dataset** dan kirim berkas
`.zip` ke peneliti.

* Semua proses terjadi **di perangkat Anda** — halaman ini tidak mengirim tulisan ke server mana pun.
* Pekerjaan tersimpan otomatis di browser; aman ditutup dan dilanjutkan (perangkat & browser yang sama).
* Berkas zip hanya berisi gambar tulisan, kode penulis (nama samaran), jenis alat tulis, dan waktu penulisan.
